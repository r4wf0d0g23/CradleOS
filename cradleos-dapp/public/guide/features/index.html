EVE Frontier tools in CradleOS

One place to inspect your infrastructure and coordinate your tribe.

Bases and structures

The Dashboard groups owned structures under their Network Nodes. Search by a base name or structure ID, inspect the contents of each base, and expand or collapse groups. Offline bases and unknown locations remain visible rather than disappearing from the directory.

Storage and storefronts

Inventory provides grid and list views for storage contents. Supported owner workflows cover deposits, withdrawals and storage access. Storefronts are separate from tribal sharing: owners configure an offer, while buyers review the item, quantity, price and access terms before signing a purchase. Owning a wallet alone does not grant access to another player's storage.

Gate access

Gate controls let eligible owners configure supported routes, access rules, tolls, passes and availability windows. Route setup requires control of the relevant gate capabilities. A pass does not override the current access rules; review the current route state before travelling.

Tribe governance

The tribe economy and voting views support treasury and governance workflows for the current deployment. Permissions and eligibility are checked for each workflow. A public overview is not a promise that every connected character can perform every action.

Public intelligence

Known Space maps the observed jump network with history and replay controls. Chain Events provides a searchable event view. Recorded activity can be incomplete: missing observations are not proof that a route or event never existed.

Origins and games

Origins is the illustrated narrative archive. The Casino includes play-money games; practice balances are not withdrawable funds. Do not infer funded wagering availability from the presence of the game interface.
