CradleOS FAQ

What is CradleOS?

CradleOS is a community-built browser application for EVE Frontier tribe governance, bases, storage, gate controls and public intel. It uses game data and Sui blockchain integrations; it does not replace the game client.

Do I need a wallet?

Not for this guide, Origins, Known Space or public event views. Character-specific tools require a supported wallet connection. The app's connection action is labelled Connect EVE Vault.

Which network does it use?

The current release serves EVE Frontier Cycle 7 on Sui testnet. Use the environment shown by the app and wallet. Prior-cycle objects and balances should not be assumed to carry into a new world.

Can CradleOS change another player's structures?

Connecting a wallet does not grant those permissions. Transactions depend on ownership, capabilities and the applicable contract rules. Supported actions are reviewed by the user and approved through the wallet.

Why is a base location unknown?

A structure can be owned and visible even when its location is not available in the current data. Unknown is a status, not a claim that the base is hidden, empty or destroyed. Use the base or structure ID to identify it.

Is Known Space a complete map of all travel?

No. It shows the jump network and activity available in the observed archive. Coverage and historical backfill may be incomplete. An absent edge or event does not prove no travel occurred.

Are storefronts the same as shared tribal storage?

No. Sharing controls who can access supported storage, while a storefront defines an offer for a buyer to review and purchase. The connected account must meet the rules for the particular action.

Can I withdraw play money from the Casino?

No. Practice game balances are not withdrawable funds. Game availability does not establish that funded wagering is enabled. Check the current mode and terms in the app.

Where can I learn more or report a problem?

Read the feature guide or setup steps. Reproducible interface problems can be reported in the project issue tracker. Use public details and never post wallet recovery phrases.
