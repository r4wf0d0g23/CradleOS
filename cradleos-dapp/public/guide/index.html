CradleOS guide

Tools for the tribe you are building in EVE Frontier.

CradleOS brings base management, storage, gate controls, tribe governance and public intelligence into one browser app. It connects EVE Frontier players with game data and supported Sui testnet transactions, while leaving wallet approval with the player.

Common questions

Wallet requirements, testnet status, permissions and the difference between observed data and complete history.

Built around game ownership

A wallet connection is not blanket permission to change a structure or move inventory. Available actions depend on the connected character, current ownership and the relevant on-chain permissions. Review the specific action in CradleOS and approve it in your wallet when you intend to proceed.

Explore without a wallet

Start with Known Space for the observed jump network, Chain Events for recorded activity, or Origins for the illustrated archive. Connecting a wallet is not required to read this guide or those public views.

Current environment

The current release serves EVE Frontier Cycle 7 on Sui testnet. Feature availability depends on the current game cycle and service state. This is a community-built project, not the official EVE Frontier client.
