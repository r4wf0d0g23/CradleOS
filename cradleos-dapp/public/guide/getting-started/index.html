Get started with CradleOS

Explore first. Connect when you need your character's tools.

1. Open the app

Visit cradleos.io in a browser with JavaScript enabled. The app currently serves EVE Frontier Cycle 7 on Sui testnet. For public information, use Known Space, Chain Events or Origins without connecting a wallet.

2. Prepare EVE Vault

Use the wallet and character associated with your EVE Frontier account. Obtain EVE Vault through official EVE Frontier resources, not an unsolicited download. Select the appropriate game environment in your wallet. Never enter a recovery phrase into a website or share one in a support request.

3. Connect your character

Choose Connect EVE Vault in CradleOS and select the intended account. Check the displayed address. If an identity-verification message is requested, inspect it in the wallet; this is distinct from approving a transaction that changes on-chain state.

4. Find your base or inventory

Open the Dashboard to find owned bases and their structures. Search by name or game item ID. In Inventory, use Grid or List to inspect storage. If a structure is missing, confirm the connected character, game cycle and ownership before assuming the inventory is gone.

5. Review before signing

For a supported change, check the selected structure, item quantities, recipient or access settings, and any cost. Sui transactions require gas, and the correct on-chain permissions must be available. Approve only the action you intend to take. Connecting alone does not submit a storage move or activate a gate route.

If something does not load

Refresh the view, check the wallet account and connection state, and try again when the service is available. An unavailable balance or location is not the same as zero. For a reproducible interface issue, include the page, time and public structure ID in a project issue; omit recovery phrases and private account information.
